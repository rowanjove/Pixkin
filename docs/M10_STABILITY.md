# M10 稳定性与可观测性

状态：`IMPLEMENTED`

验收日期：2026-09-12

## 1. 诊断与隐私边界

- 运行日志使用带 schema 版本、应用版本、组件、操作和错误类别的结构化 JSON 事件。
- 日志采用 2 MiB、3 个文件的滚动上限；崩溃摘要最多保留 10 份。
- 未捕获异常只在本地生成脱敏摘要，不会自动上传。
- 匿名诊断包只能由用户主动导出，且只包含 `manifest.json`、`runtime.json`
  和 `crashes.json`；清单记录每个文件的大小和 SHA-256。
- 日志、崩溃摘要、诊断包、聊天数据库和工具审计共用密钥与路径脱敏规则。

## 2. 网络与 Provider 恢复

- Chat Provider 的健康检查不会发送聊天内容，可列出模型并检查配置模型是否存在。
- 认证、权限、模型不存在、限流、超时、服务端、工具不兼容、连接和协议错误具有不同恢复建议。
- 失败回复可以在保留当前上下文的前提下重试，不会重复持久化用户消息。
- 直播房间独立执行带抖动的指数退避；探测失败保留最后可信直播状态。
- 托盘可查看每个房间的最后成功时间、连续失败次数和下次重试时间。

## 3. 数据恢复

- 旧聊天数据库在迁移前执行 `quick_check` 和一致性 SQLite 备份。
- 数据库损坏时默认停止写入，提供只读导出、备份后重建或退出三种入口。
- “备份全部本地数据”覆盖配置、聊天、角色、伙伴工坊任务和用户资料。
- 恢复包执行白名单、路径、符号链接、文件数、大小、总量和 SHA-256 校验。
- 恢复先进入暂存区并在下次启动、打开配置和数据库之前应用；现有数据先移入
  `backups/restore-<id>`，失败时自动回滚。

## 4. Windows 性能基线

首个可比较基线位于
[`docs/performance/windows-10-baseline.json`](performance/windows-10-baseline.json)。
它是新建立的首版基线，没有上一稳定版本可用于退化比较。后续版本必须在同类环境运行：

```powershell
py -3.11 scripts\measure_performance.py `
  --output artifacts\performance\candidate.json `
  --executable dist\Pixkin\Pixkin.exe `
  --duration 20 `
  --compare docs\performance\windows-10-baseline.json
```

关键延迟、CPU 或内存相对基线退化超过 10% 时，脚本返回退出码 2 并列出指标；
发布前必须修复，或在发布说明中记录原因与影响。状态数量属于容量指标，不按
“越低越好”比较。

本轮 Windows 10 19045 / AMD64 基线（文件夹版预热 2 秒后连续测量 20 秒，三次独立运行取中位数）：
