# M9 安全、隐私与工具权限实施说明

状态：`completed`
目标版本：`1.5.0`

## 已完成：密钥存储基线

- 对话与图像 API Key 只允许持久化到 Windows Credential Manager。
- 设置中心和伙伴工坊在凭据保存失败时阻断操作，不再回退写入 `config.json`。
- 聊天 Worker 只读取 `SecretStore`，不会消费配置文件中的旧明文 Key。
- 启动时同时迁移 `api.api_key` 与 `image_generation.api_key`。
- 迁移顺序为“保存凭据 → 原子清空配置”；配置清理失败时恢复迁移前凭据，
  并保留原明文值供用户修复后重试。
- 旧 `DesktopPet/OpenAICompatibleAPI` 凭据仍会迁移到新的 Pixkin 目标；
  删除旧目标失败时撤销新目标，避免出现无法确认的半迁移状态。
- 自动化测试覆盖迁移成功、配置清理失败回滚、凭据不可用时 UI 阻断，
  以及聊天 Worker 不读取明文回退。

## 已完成：工具权限与审计

- `ToolPermissionLevel` 定义 L0 只读、L1 外部动作、L2 状态修改和 L3 高风险。
- 每个注册工具声明等级和副作用摘要；L0 自动执行，L1 缺少逐次确认回调时拒绝，
  L2/L3 即使存在 L1 确认回调也默认拒绝。
- 当前时间、系统信息、安全计算、磁盘容量和工具列表为 L0；
  打开白名单应用与 HTTP(S) 网页为 L1。
- 授权、拒绝、成功和错误均生成审计事件，记录工具、等级、脱敏参数、
  授权方式、结果和耗时。
- 参数审计会隐藏密钥字段、URL 用户信息、敏感查询值和片段。
- `cmd.exe` 已从默认应用白名单和工具描述中移除。
- L1 请求由 Worker 安全桥接到 Qt 主线程，确认框默认选择拒绝；应用退出或
  会话切换会释放等待中的 Worker，不会阻塞退出。
- 用户可以在本次运行中记住“同一工具 + 同一脱敏参数”的决定；退出时清空。
- 审计按原子 JSON 文件持久化，最多保留 1000 条且不超过 1 MiB。
- 设置中心可查看、导出和清除审计；记录包含会话编号、结果与耗时。

## 已完成：聊天隐私与本地保留

- 首次发送给模型前展示接口地址、发送内容范围和本地保存位置，拒绝则不发送。
- 设置中心提供不保存、7 天、30 天和永久四档；到期消息自动清理。
- “不保存”会清空旧记录，运行期间只在内存保留上下文。
- 历史窗口支持按角色一键清理，以及“导出后删除所见”。
- 对话和图像 Key 均可选择仅本次运行使用，不写入凭据管理器，退出时清空。
- 日志、聊天数据库、工具审计和伙伴工坊问题包使用密钥模式脱敏。

## 已完成：角色包信任

- 内置与官方可选角色 ZIP 均由随应用发布的 SHA-256 清单验证，篡改时拒绝安装或更新。
- 第三方角色包在安装前展示作者、许可声明、文件数量和包指纹。
- 第三方作者声明只作为提示，不自动提升为官方信任。

## DPAPI 评估结论

消息内容应用层 DPAPI 加密暂不默认启用。当前 SQLite 历史支持跨版本迁移、
只读导出和用户主动清理；直接绑定当前 Windows 用户会增加系统重装、账户迁移和
故障恢复时的数据丢失风险。后续若提供加密，应采用显式 opt-in、带版本信封、
启动前备份和恢复密钥可用性检查，不能以不可恢复的原地改写上线。
