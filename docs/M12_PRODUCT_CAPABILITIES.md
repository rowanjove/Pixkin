# M12 产品能力增强：设计、隐私边界与验收

状态：`IMPLEMENTED`

M12 在不购买代码签名证书的范围内完成五个相互独立的产品主题。所有新增网络能力
默认关闭或需要用户明确动作；长期记忆、录音、角色覆盖和提醒策略均有本地可见控制。

## 1. 可控长期记忆

- `MemoryService` 使用有数量、单条长度和注入总量上限的原子 JSON 存储。
- 候选只从本机用户消息中的“请记住 / 我叫 / 我喜欢 / 我希望”等明确表达提取。
- 提取不会写入；用户必须逐条点击“确认保存所选候选”。
- 记忆按稳定本机用户标识和角色 ID 分区，支持查看、编辑、停用、删除和总开关。
- 常见凭据形状不会进入候选或存储。
- 每次回复的 `used_memories` 元数据只记录本次实际注入项，聊天气泡可展开查看。
- `memories.json` 已进入统一备份、哈希校验和启动前恢复白名单。

隐私边界：关闭总开关后不注入任何记忆；记忆不会因为聊天历史启用而自动创建。
启用时，只有当前角色的已确认项会随对应模型请求发送。

## 2. 语音与全局快捷键

- 语音采用按住说话：按下后才打开默认麦克风，松开或 60 秒到期立即停止。
- 原始 PCM 和 WAV 只存在内存中；Pixkin 不把录音写入用户目录。
- 转写端点、模型和独立 API Key 与聊天模型分开配置。
- 语音凭据只进入 Windows Credential Manager 或本次运行内存。
- 首次录音前单独展示端点、发送范围和服务商保留策略提示。
- 转写结果只放入输入框，用户确认后才作为聊天消息发送。
- 聊天窗口持续显示“关闭 / 静音 / 待命 / 录音 / 转写”状态。
- 全局快捷键覆盖显示/隐藏、打开聊天、停止生成和麦克风静音；注册冲突会提示，
  退出时全部注销。

限制：当前录音格式为 16 kHz、单声道、16-bit PCM；不支持该格式的设备会明确报错，
不会静默改为常驻监听。真实麦克风、驱动和转写服务仍需在发布候选机上做硬件冒烟。

## 3. 角色生态

- 独立 ZIP 检查器在不安装的情况下展示预览、角色身份、版本、作者声明、文件数、
  兼容性和完整 SHA-256 指纹。
- 官方身份只来自随应用打包的不可变哈希清单；相同作者名不会获得官方信任。
- 内置目录使用严格 HTTPS URL、SemVer、SHA-256 和应用版本边界。
- 目录客户端可发现兼容更新、无凭据无重定向下载、限制 100 MB、原子落盘并校验哈希。
- 官方角色更新必须再次确认，安装前重验包 ID 和版本；第三方条目不能走官方更新路径。
- 第三方目录只提供来源类型与指纹，不默认信任作者声明。
- 角色行为编辑器按角色保存动作权重、冷却和贴边露出覆盖；双击动作可即时预览。
- 覆盖只写本机配置，不修改角色 ZIP、`character.md` 或官方哈希。

外部角色索引若要上线，仍需随应用发布受信目录或增加独立签名清单；不能仅依赖 HTTPS
页面上的作者字段。

## 4. AI 体验

- 提供快速、均衡、深入三个回答预设。
- 每条成功回复显示本地估算的延迟、输入/输出 token 和费用。
- 输入/输出单价由用户配置；估算值不冒充服务商账单。
- 聊天窗口提供可见的停止生成、失败重试和用户消息“编辑并重发”。
- 模型设置页显示流式、Tool Calls、取消和健康检查能力。
- `ChatService` 在发送任务前执行能力预检；流式或 Tool Calls 不受支持时不调用 Provider。
- 超时、认证、权限、限流、模型不存在、协议和能力不兼容继续使用分类恢复提示。

## 5. 直播与提醒

- `LiveProviderRegistry` 定义 `pixkin.live_providers` entry-point 协议；只加载用户显式
  启用、API 版本匹配、支持状态检测和安全 URL 校验的适配器。
- B 站链接只接受精确 `https://live.bilibili.com/<id>`；抖音只接受受信后缀的 HTTPS
  地址，短链逐跳验证并限制跳转次数。
- 直播凭据按平台和房间哈希分区保存到 Windows Credential Manager。
- 旧配置或插件传入的明文 `cookie` 字段不会被内置 Provider 消费。
- 提醒支持跨午夜免打扰、静默结束后补提醒、可选重复提醒间隔和房间分组。
- 平台失败继续保留最后可信状态并采用房间级退避。
- 常驻直播监听需要会话级或永久网络授权，单次 ASK 同意不会被延长为后台常驻访问。
- 内置响应样本、URL 攻击样本、凭据隔离和插件协议均有契约测试。

## 6. 数据和兼容性

- 配置采用递归默认合并，旧配置无需迁移即可获得 M12 默认值。
- 语音默认关闭；记忆默认开启但没有确认条目时不会发送额外内容。
- 快捷键和角色行为覆盖均可关闭或删除，不改变角色包格式。
- 直播房间未设置分组时保持旧序列化结构，旧配置继续有效。
- 安装、更新和回滚前的统一备份现已包含长期记忆。
